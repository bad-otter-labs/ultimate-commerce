A modular commerce experience enhancement platform for WooCommerce.

== Description ==

Ultimate Commerce for WooCommerce keeps WooCommerce authoritative for products, variations, stock, carts, totals, tax, customers, orders, payments and refunds while adding reusable storefront and customer-experience capabilities.

This Free package is designed to be useful without Ultimate Commerce Pro, a Bad Otter account or a proprietary theme. Paid Ultimate Commerce Pro modules are distributed separately and consume documented public contracts exposed by Free.
